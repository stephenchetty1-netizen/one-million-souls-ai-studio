# Operations Hub — two-workspace controller

One coordinated workbench, with independent **One Million Souls** and **OneHub AI Business** pipelines. No cross-posting, shared customer records, assumed payments, automated certification, or auto-deploys.

## Workspaces

| Stage | One Million Souls | OneHub AI Business |
|---|---|---|
| 1 | Research | Offer research |
| 2 | Scripture script / storyboard | Content strategy |
| 3 | Rights-safe asset sourcing | Creative production |
| 4 | Production | Offer & rights QA |
| 5 | Technical / creative QA | Human approval |
| 6 | Final master human review | Organic distribution handoff |
| 7 | Approved distribution handoff | Lead / referral review |
| 8 | Real performance measurement | Verified sales measurement |

**Global hard stops:** no paid AI API calls, no social posting, no customer contact, no payment creation, no autonomous release. Work planning is not actual agent execution.

**OMS approval:** full creative/technical/content/rights checklist, narrative evidence, exact MP4 SHA-256, explicit human review. This board's approval is not a V59 media certificate and does not unlock publishing.

**OneHub approval:** offer/price/deliverables/rights checks, evidence, and human review. An enquiry or task completion is not verified revenue. Payment needs independent PayPal confirmation.

The working mobile-friendly **standalone dashboard** is a separate generated HTML deliverable for direct Android use. The JS workflow engine and its tests are tracked on this branch. The dashboard is local-browser-only and does not sync with V59, Floot or social platforms. Credentials and customers' data must not be entered into its local storage.

Integrations should be added only via authenticated server-side adapters once the original Floot build-action limit is available. The existing OneHub live sales page and OMS Railway services are intentionally unchanged.
